# Coherent-State Assisted Entanglement Distribution: Manuscript Data Release

This folder is a compact GitHub-ready reproduction package for the data used in
the selected manuscript figures.  It is separate from the larger working
directory, which contains exploratory scans, smoke tests, and intermediate
diagnostics.

## Receiver Convention

The main-text QAM curves use the full-state/raw-label square-root measurement
(SRM): the joint vacuum component is kept when constructing Charlie's SRM.
The End Matter compares this receiver with a vacuum-omitting SRM.

## Quick Start

Create a Python environment and install the lightweight requirements:

```bash
python -m pip install -r requirements.txt
```

Generate all per-subfigure CSV tables from the curated data:

```bash
python scripts/make_all_subfigure_data.py
```

Or validate the release:

```bash
python scripts/validate_release.py
```

For a small source-code-to-data audit, run:

```bash
python scripts/spot_check_simulation_samples.py
```

Outputs are written to:

```text
outputs/subfigure_data/
outputs/validation/
```

## Subfigure Data Scripts

Each script is annotated and writes a small CSV table:

- `scripts/get_fig1c_data.py`
  - Fig. 1(c): QAM hashing bound versus channel loss using full-state SRM.
- `scripts/get_fig2a_data.py`
  - Fig. 2(a): optimized QAM spacing `d` versus channel loss.
- `scripts/get_fig2b_data.py`
  - Fig. 2(b): hashing bound versus `d` at fixed channel losses.
- `scripts/get_fig3_interface_loss_data.py`
  - Fig. 3(a,b): interface-loss scan at `0.25 dB` per-arm channel loss.
- `scripts/get_fig3_phase_bias_data.py`
  - Fig. 3(c,d): systematic phase-bias scan for interface losses `0.1` and
    `0.2 dB`.
- `scripts/get_fig5a_data.py`
  - End Matter Fig. 5(a): full-state SRM versus vacuum-omit SRM.
- `scripts/get_fig5b_data.py`
  - End Matter optimized-POVM comparison: full-state SRM versus best-found
    32-outcome POVM for 4-QAM.
- `scripts/spot_check_simulation_samples.py`
  - Recomputes representative saved points from the release source tree and
    writes a pass/warn/fail audit table.

## Loss Convention

Most simulation files use `loss_db` as the per-arm channel loss from Alice to
Charlie, and independently from Bob to Charlie.  For a symmetric midpoint link,
the corresponding end-to-end Alice-Bob dB loss is twice this number.  The
subfigure CSVs include both:

- `loss_db_per_arm_code`
- `end_to_end_loss_db_midpoint`

For Fig. 3, the manuscript setting `L_ch = 0.5 dB` corresponds to
`channel_loss_db_per_arm_code = 0.25 dB`.

## Folder Layout

```text
scripts/
  Annotated, figure-specific extraction scripts.

manuscript_reproduction/
  Shared path and CSV helpers.

  Generated per-subfigure CSVs. This folder can be deleted and regenerated.
```

## Heavy Regeneration

The scripts in `scripts/` do not rerun the expensive simulations.  They extract
and normalize the selected saved data.  The underlying code used for expensive
regeneration is preserved under `source_code/`.

Important expensive components:

- 32-QAM SRM scans are expensive because the received optical span has
  `M^2 = 1024` labels.
- The 16-QAM interface-loss transition is expensive because several local
  spacing branches must be tracked.
- The 32-outcome 4-QAM POVM search is a nonconvex multi-start optimization on
  a Stiefel manifold.  The saved value is a best-found lower bound, not a
  mathematical global-optimality certificate.

## Reproducibility Spot Check

`scripts/spot_check_simulation_samples.py` recomputes representative SRM points
for ideal channel loss, fixed-`d` sweeps, interface loss, phase bias, and the
SRM baselines used beside the optimized POVM.  It also checks the saved
32-outcome POVM matrix metadata, verifies `A^\dagger A = I`, and reevaluates
the saved matrix with the copied optimizer objective.

For the optimized POVM, the saved NPZ file is treated as the canonical record.
The subfigure and validation scripts load that metadata automatically.

## Fig. 1(c) External Baselines

This release exports the QAM SRM curves generated by the project code.  Fig.
