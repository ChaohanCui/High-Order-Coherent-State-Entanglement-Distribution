# External Baselines for Fig. 1(c)

The project code in this release generates the QAM full-state SRM curves.  The
published Fig. 1(c) also includes external or analytic baselines:

- PLOB
- CTW coherent two-way protocol
- single-photon baselines
- finite-squeezing Hex-GKP benchmarks

Those values are not generated by the QAM SRM simulation scripts.  If the final
plotting script is published, place the numeric baseline CSVs in this folder
and include citations/source notes for each curve.
